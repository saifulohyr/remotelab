Panduan Instalasi SIMLab Agent
SMK MUHAMMADIYAH MAJENANG • Remote Lab Management & WoL Relay
Paket agen Windows sudah dikonfigurasi langsung mengarah ke Cloudflare Online (https://simlab.labmuma.xyz).
1 Unduh dan Ekstrak Paket

Unduh file simlab-agent-windows.zip, lalu ekstrak seluruh isinya ke folder yang aman (disarankan di C:\simlab-agent\).

Unduh simlab-agent-windows.zip
2 Atur Kode Lab & ID di config.yaml

Buka file config.yaml dengan Notepad. Pembeda ID sangat mudah:

lab:
  lab_id: "lab-rpl-1"  # Pilih: lab-rpl-1 s/d 4, lab-bahasa, lab-rps
  pc_id: "auto"       # PC SISWA: biarkan "auto" (baca nama Windows)
  # pc_id: "komguru"    # KHUSUS PC GURU: isi "komguru"
Pembeda Komguru: Cukup isi pc_id: "komguru" di PC Guru. Di dashboard SIMLab, kartu PC Guru akan otomatis tampil paling atas dan terpisah sebagai Master Relay WoL ruangan.
3 Jalankan dan Verifikasi

Klik ganda simlab-agent.exe. Jendela akan menampilkan status koneksi:

[Agent] Connected to server: https://simlab.labmuma.xyz
[Telemetry] Ingest success: 200 OK | Hostname: RPL1-PC01 | MAC: 00:1A:2B:3C:4D:5E

Buka konsol di simlab.labmuma.xyz — kartu PC akan otomatis berubah hijau (Online) dan MAC address terdaftar otomatis.

4 Agar Berjalan Otomatis saat Komputer Nyala (Auto-Start)

Metode A (Mudah): Tekan Win + R → ketik shell:startup → tekan Enter. Klik kanan simlab-agent.exe → pilih Create Shortcut → pindahkan shortcut ke dalam folder startup tersebut.

Metode B (Background Service via Task Scheduler): Buka CMD Administrator, jalankan 1 perintah ini:

schtasks /create /tn "SIMLabAgent" /tr "C:\simlab-agent\simlab-agent.exe" /sc onstart /ru SYSTEM /rl HIGHEST /f

Struktur lengkap file config.yaml:

server: url: "https://simlab.labmuma.xyz" mqtt: broker_host: "simlab.labmuma.xyz" broker_port: 8883 use_tls: true lab: lab_id: "lab-rpl-1" # ID ruangan lab pc_id: "auto" # auto / nama PC spesifik agent: version: "1.0.0" telemetry_interval_sec: 15
Daftar ID Lab Resmi SMK MUHAMMADIYAH MAJENANG:
  • LAB RPL 1 lab-rpl-1
  • LAB RPL 2 lab-rpl-2
  • LAB RPL 3 lab-rpl-3
  • LAB RPL 4 lab-rpl-4
  • LAB Bahasa lab-bahasa
  • LAB RPS lab-rps
Solusi Topologi Beda Router Router lab memblokir Magic Packet broadcast antar-ruangan. SIMLab mengatasi ini dengan sistem Peer-Relay tanpa perlu mengubah topologi router ataupun menarik kabel baru ke server Debian.
  1. Cukup 1 PC Guru / Komguru Nyala di Tiap Lab: Pasang SIMLab Agent di PC Guru (misal RPL1-KOMGURU). Saat pagi hari, nyalakan PC Guru terlebih dahulu.
  2. Server Menugaskan PC Guru via Cloud: Saat Anda menekan tombol Wake-on-LAN dari HP di simlab.labmuma.xyz, server Debian mengirimkan daftar MAC address PC siswa ke PC Guru yang sedang online tersebut.
  3. Eksekusi Broadcast Lokal: Agen di PC Guru langsung menyebarkan paket UDP broadcast (port 9) ke seluruh switch lokal lab. Seluruh 30+ PC siswa dalam lab tersebut langsung menyala bersamaan.
Tips Alternatif: Auto Power ON (AC Back)

Jika ingin semua PC langsung menyala otomatis begitu MCB listrik lab dihidupkan tanpa perlu WoL: masuk ke BIOS motherboard → menu Power Management / APM → ubah Restore AC Power Loss menjadi Power On.

Jalankan perintah berikut pada terminal Ubuntu / Debian di PC klien atau STB Armbian:

# 1. Unduh dan ekstrak
wget https://labmuma.xyz/downloads/simlab-agent-linux.tar.gz
tar -xzf simlab-agent-linux.tar.gz -C /opt/simlab-agent/

# 2. Edit konfigurasi lab_id
nano /opt/simlab-agent/config.yaml

# 3. Jalankan sebagai systemd service
sudo /opt/simlab-agent/simlab-agent -service install
sudo systemctl start simlab-agent
sudo systemctl enable simlab-agent
