Panduan Instalasi SIMLab Agent
SMK MUHAMMADIYAH MAJENANG • Remote Lab Management & WoL Relay
Paket sudah dikonfigurasi ke https://simlab.labmuma.xyz. Tidak perlu edit server URL.
1 Unduh & Ekstrak

Ekstrak isi zip ke folder C:\simlab-agent\

simlab-agent-windows.zip
2 Atur config.yaml

Buka config.yaml dengan Notepad, ubah lab_id sesuai ruangan:

lab:
  lab_id: "lab-rpl-1"  # lab-rpl-1 s/d 4 | lab-bahasa | lab-rps
  pc_id:  "auto"    # PC SISWA: biarkan auto
                # PC GURU : isi "komguru"
PC Guru cukup isi pc_id: "komguru" — otomatis tampil paling atas & jadi relay WoL ruangan.
3 Jalankan & Verifikasi

Klik ganda simlab-agent.exe. Pastikan muncul:

[Agent] Connected to server: https://simlab.labmuma.xyz
[Telemetry] Ingest success: 200 OK | Hostname: RPL1-PC01

Kartu PC akan muncul otomatis di simlab.labmuma.xyz.

4 Auto-Start saat Komputer Nyala

Metode A (Mudah): Win + R → ketik shell:startup → Enter → buat shortcut simlab-agent.exe ke sana.

Metode B (Service — Direkomendasikan):

schtasks /create /tn "SIMLabAgent" /tr "C:\simlab-agent\simlab-agent.exe" /sc onstart /ru SYSTEM /rl HIGHEST /f

Struktur lengkap file config.yaml:

server:
  url: "https://simlab.labmuma.xyz"

mqtt:
  broker_host: "simlab.labmuma.xyz"
  broker_port: 8883
  use_tls:    true

lab:
  lab_id: "lab-rpl-1"     # ID ruangan lab
  pc_id:  "auto"        # auto / nama PC spesifik

agent:
  version:             "1.0.0"
  telemetry_interval_sec: 15
Daftar ID Lab Resmi
# Lab RPL     lab-rpl-1  |  lab-rpl-2  |  lab-rpl-3  |  lab-rpl-4
# Lab Lain   lab-bahasa  |  lab-rps
Router lab memblokir Magic Packet antar-ruangan. SIMLab mengatasi ini dengan sistem Peer-Relay — tanpa ubah topologi.
1

Nyalakan PC Guru terlebih dahulu

Pasang SIMLab Agent di PC Guru (RPL1-KOMGURU). Saat pagi, PC Guru dinyalakan manual lebih awal.

2

Tekan WoL dari konsol

Server mengirim daftar MAC address PC siswa ke PC Guru yang online via Cloudflare Tunnel.

3

PC Guru relay ke LAN lokal

Agen mengirim Magic Packet UDP broadcast (port 9) ke switch lokal. Seluruh 30+ PC menyala bersamaan.

Tips: Supaya semua PC menyala otomatis saat MCB dihidupkan tanpa WoL — masuk BIOS → Power Management → ubah Restore AC Power Loss ke Power On.

Jalankan pada terminal Ubuntu / Debian / Armbian:

# 1. Unduh dan ekstrak
wget https://labmuma.xyz/downloads/simlab-agent-linux.tar.gz
tar -xzf simlab-agent-linux.tar.gz -C /opt/simlab-agent/

# 2. Edit konfigurasi
nano /opt/simlab-agent/config.yaml

# 3. Install sebagai systemd service
sudo /opt/simlab-agent/simlab-agent -service install
sudo systemctl enable --now simlab-agent
